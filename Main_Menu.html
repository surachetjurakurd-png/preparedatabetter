เอาไว้ใช้สำหรับ Prepare Data for Onboarding Module ของ KKP Better

Primary Feature

🇹🇭 Thai Customer IAL 2.3
สร้างลูกค้าชาวไทย Default IAL 2.3
🇹🇭 Thai Customer IAL 1.3
สร้างลูกค้าชาวไทย Default IAL 1.3
🇹🇭 Thai Customer IAL 2.1
สร้างลูกค้าชาวไทย Default IAL 2.1
🌐 Foreigner Customer
สร้างลูกค้าชาวต่างชาติ Foreigner

Other Tools

🔐 KKP Channel Verification
ใช้สำหรับ Bypass การยืนยันตัวตนผ่าน KKP
🖼️ Get Customer Image
ตรวจสอบใบหน้าของ Customer จากเลขบัตรประชาชน
🧰 Convert image to Base64
เลือกรูปจากเครื่อง (ไม่เกิน 2MB) แล้วแปลงเป็น Base64
📱 Remove Device
ลบอุปกรณ์จาก KKP Better ด้วยเลขบัตรประชาชน
💰 เติมเงินเข้าบัญชีผ่าน Service ATS
โอน/เติมเงินเข้าบัญชีผ่าน Service ATS รองรับ SIT และ UAT
🔎 Get Customer Profile From Account number
ค้นหา Customer Profile จากเลขที่บัญชี Account Number
🧾 Get Account from Customer ID
ค้นหา Account Number ทั้งหมดจาก Customer ID ผ่าน ACS Service
🛑 Cancel State For Onboarding
Cancel Resume State เมื่อผู้ใช้ไม่สามารถทำรายการต่อได้

⚙️ Setup Required - โปรดอ่านให้ครบ ก่อนใช้งานเว็บ ▼

📋 ขั้นตอนการตั้งค่า:

  1. เปิด Terminal บน OS Mac หรือ CMD บน Windows
  2. เปลี่ยนไปยังโฟลเดอร์ที่มี proxy-server.js (เช่น cd ./Documents/Download/WebCreateForeigner) หากเป็น Mac OS สามารถคลิกขวาแล้วเลือก New Terminal at Folder
  3. รันคำสั่ง proxy server:
    node proxy-server.js📋 Copy
  4. รอจนเห็น: ✅ Proxy server running at http://localhost:3000 อันเป็นใช้ได้ และห้ามปิด Terminal หรือ CMD ขณะใช้งานเว็บ
  5. ติดต่อขอรับไฟล์ proxy-server.js ได้ที่ Surachet Jurakurd (Champ) 🤓
